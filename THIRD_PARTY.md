# Third-party

Domínio e telas do AssetHub são originais — nenhum código ou markup foi copiado de um
projeto OSS externo (não é port de um repositório de terceiros).

Bibliotecas de UI usadas (todas MIT, instaladas via `package.json`, não copiadas manualmente):

- [shadcn/ui](https://ui.shadcn.com/) — componentes em `src/components/ui/**`.
- [Radix UI](https://www.radix-ui.com/) — primitivos por trás do shadcn/ui.
- [Lucide](https://lucide.dev/) — ícones.
- [Recharts](https://recharts.org/) — gráficos do dashboard.
- [TanStack Query](https://tanstack.com/query) — cache de estado do servidor.
- [React Router](https://reactrouter.com/) — roteamento (SPA, `react-router-dom` 7).

Se, no futuro, alguma tela ou modelo de dados for adaptado a partir de um projeto OSS
específico, registre aqui: nome do projeto, link, licença e o que foi copiado.
